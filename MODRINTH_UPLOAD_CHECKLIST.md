# Modrinth Upload Checklist

Use this checklist for each Cobble Spawn Control release.

## Before building

- [ ] Confirm the Minecraft version.
- [ ] Confirm the mod loader and its version.
- [ ] Confirm the required Cobblemon version.
- [ ] Update the compatibility table in `README.md`.
- [ ] Update `CHANGELOG.md`.
- [ ] Confirm the mod version in the build files and metadata.

## Verify the build

- [ ] Produce the release `.jar`.
- [ ] Test the release in a clean Minecraft instance.
- [ ] Confirm the mod loads with the documented dependencies.
- [ ] Confirm configuration files are created and work as expected.
- [ ] Check that no development-only or private files are included.

## Modrinth project links

- **Source:** `https://github.com/jezielcamara/cobble-spawn-control`
- **Issues:** `https://github.com/jezielcamara/cobble-spawn-control/issues`

## Upload

- [ ] Select the correct Minecraft and loader versions.
- [ ] Mark required and optional dependencies accurately.
- [ ] Add release notes based on `CHANGELOG.md`.
- [ ] Upload the tested release `.jar`.
- [ ] Publish a matching GitHub release and tag.
- [ ] Add the Modrinth project URL to `README.md` after the first publication.
